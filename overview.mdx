<Update label="September 22, 2026">
  ## v2026.09.22

  ### New

  - A new composer-first Home replaces the separate Assistant landing page. Start a conversation straight from Home, with attachments and model and verification controls built in.
  - Context Library brings semantic context, Skills, and Tables together in one tabbed view, with shared filters, statuses, review workflows, and detail pages.
  - Artifacts now have types, list and grid views, and status filters, and refreshing an artifact creates an updated snapshot.
  - Download the original file behind any file upload connection.
  - Undo and redo text with Command+Z and Command+Shift+Z.

  ### Improvements

  - A refreshed visual design across the app, with a new light and dark palette, Plus Jakarta Sans typography, flat tables, simpler dot-and-text statuses, and updated controls, headers, filters, and sidebar.
  - Organization admins can now manage roles and permissions from Settings.
</Update>

<Update label="September 15, 2026">
  ## v2026.09.13

  ### New

  - Connect Harvest and bring in time tracking and project billing data.
  - Cloud support for Infor SyteLine ERP.
  - Schedule data source syncs to run on a recurring or date-based schedule, instead of running them by hand.
  - A redesigned metric editor, with guided sections, source and filter pickers, live previews, and descriptions that persist.
  - Metric suggestions now ask before they apply, so you can accept or dismiss a proposal before it changes your metric.

  ### Improvements

  - Grounding is now called Verification, with three levels in a single picker: Standard for quick questions and exploring your data, Enhanced for management reporting and financial decisions, and Thorough for board, investor, or audit-sensitive work.
  - Internal navigation now sits in its own section at the bottom of the sidebar, above Inbox, in both the expanded and collapsed states.
</Update>

<Update label="September 9, 2026">
  ## v2026.09.9

  ### New

  - Artifact version history, so every refresh keeps the previous version available to view.
  - A resizable split view with per-artifact tabs that remember their panel state.
  - Ask how a figure in an uploaded spreadsheet was built. Pluvo now reads the formulas behind your Excel cells and can explain the formula behind a total, what a column header means, and how sheets reference each other. Reported figures still come from your synced data, never from a cell value.

  ### Improvements

  - Edit an artifact directly from the artifact list and view pages.
  - Clearer source and resource context behind an answer, including metrics, skills, and source logos.
  - Derived facts now show their values instead of raw IDs, and you can navigate through the facts that compose them.
  - Connections now identify their ERP entity and currency, so two connections of the same type can be told apart.
  - Organization-required skills now apply reliably when the Assistant replays a conversation.
</Update>

<Update label="April 7, 2026">
  ## v1.16.0

  Pluvo version 1.16.0 drops in the next couple of days. Highlights below.

  ### Refreshed settings pages

  All settings pages have been updated to match Pluvo's current look and feel. Functionality is unchanged — just much shinier.

  ### Improved user permissions

  - **New `Guest` role.** Limited to view and comment actions, no editing. Designed for department heads, board members, and others who need visibility into the business in Pluvo but shouldn't be editing data.
  - **Base scenario merges restricted to admins.** Previously, anyone with edit access to the base scenario could merge into it.
  - **Members now have edit access to the base scenario by default.** Previously, members only had view access, which caused confusion when onboarding colleagues.
</Update>
