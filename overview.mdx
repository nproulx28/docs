<Update label="June 25, 2026">
  ## v2026.06.25

  ### New

  - Re-sync a single data table on demand, without re-running the whole sync.

  ### Improvements

  - Analysis reports now follow Pluvo's Report Style Guide, with cleaner headings, easier-to-read text, tidier tables, clickable source numbers, and color-coded severity badges that now include "info" and "resolved" levels. This affects reports only, not the AI chat.
  - Faster data syncing, previewing, and downloading, including quicker CSV exports and support for more file types and custom integrations.
  - New analysis sessions are now private by default.

  ### Fixes

  - Wide tables in analysis reports no longer get cut off. They now scroll sideways within their own box, with a subtle fade at the edges to show there is more to see.
  - The comments and run-history panels no longer cover the top bar. They now slide out below it and gently push the page content aside.
  - Healthy API and accounting connections (like QuickBooks and Xero) no longer show a confusing "Unmapped" label that was only ever meant for file uploads.
</Update>

<Update label="June 15, 2026">
  ## v2026.06.22

  ### Improvements

  - Data sources are now grouped by connection type in the list view, so they are easier to scan.
  - Xero connections now show the authenticated organizations, so you can pick which one to configure.
  - Refreshed shadows and text styles across key pages for a cleaner look in light and dark mode.
  - Deep Analysis settings now use a three-dot menu with a simpler scheduling flow.

  ### Fixes

  - Table totals no longer offer an inconsistent click-through when the underlying data is row-level.
  - Analysis reports now render separate tables correctly when findings include both bills and invoices.
  - Removed an unexpected bar chart that could appear in the middle of analysis results.
</Update>

<Update label="April 7, 2026">
  ## v1.16.0

  Pluvo version 1.16.0 drops in the next couple of days. Highlights below.

  ### Refreshed settings pages

  All settings pages have been updated to match Pluvo's current look and feel. Functionality is unchanged — just much shinier.

  ### Improved user permissions

  - **New `Guest` role.** Limited to view and comment actions, no editing. Designed for department heads, board members, and others who need visibility into the business in Pluvo but shouldn't be editing data.
  - **Base scenario merges restricted to admins.** Previously, anyone with edit access to the base scenario could merge into it.
  - **Members now have edit access to the base scenario by default.** Previously, members only had view access, which caused confusion when onboarding colleagues.
</Update>
